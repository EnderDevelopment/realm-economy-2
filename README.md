# Realm Economy

Realm Economy is a complete, reliable, multiplayer-compatible economy system for Minecraft Bedrock Realms. It allows players to earn, transfer, and spend currency, participate in jobs and quests, and compete on leaderboards. The system uses Minecraft scoreboards for currency storage and dynamic properties for additional persistent data, ensuring it works even when the Realm owner is offline.

## Install

1. Download the plugin JAR file from the [Releases](https://github.com/EnderDevelopment/Realm-Economy/releases) page.
2. Place the JAR file in the `plugins` folder of your Minecraft Bedrock Realm server.
3. Start or restart your server to load the plugin.

## Use

1. **Check your balance**: Use the `/balance` command to see your current currency amount.
2. **Transfer money**: Use the `/pay <player> <amount>` command to send money to another player.
3. **Access the shop**: Use the `/shop` command to open the server shop and buy or sell items.
4. **View jobs**: Use the `/jobs` command to see available jobs and earn currency by completing them.
5. **View quests**: Use the `/quests` command to see available quests and earn rewards by completing them.
6. **View the leaderboard**: Use the `/leaderboard` command to see the top players by currency amount.
7. **View transaction history**: Use the `/transactions` command to see your recent transactions.
